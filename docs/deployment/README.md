# Deployment

Vercel (Recommended): Connect GitHub repo at vercel.com/new, set environment variables (`DATABASE_URL`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `R2_*`, `CRON_SECRET`), and deploy.

For complete deployment and self-hosting instructions, see [Deployment & Self-Hosting Guide](./index.md).
